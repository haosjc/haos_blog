## 关于本站

欢迎来到 **Hao's Notes** 🟡

这是一个以 **弥散光感 · 明快黄** 为视觉风格的个人技术博客，基于 [Hexo](https://hexo.io/) 与 [Butterfly](https://butterfly.js.org/) 主题搭建。整站主题完全通过**配置文件**与 `source/` 下的自定义资源实现，未改动任何框架或主题源码。

### 主题设计语言

| 维度 | 说明 |
| --- | --- |
| 弥散光感 | 柔和渐变光斑、玻璃拟态卡片、光晕弥散、极光色调 |
| 明快黄 | 主色 `#FFC700`，辅以蜜桃、香芋紫、薄荷绿、天空蓝的柔和渐变 |

### 内容方向

- **前端开发**：JavaScript / CSS / 工程化 / 框架实践
- **芯片基础知识**：集成电路、半导体物理、数字电路入门
