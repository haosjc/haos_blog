## 锁存器

#### SR锁存器

SR锁存器（Set-Reset Latch）属于静态存储单元的一种。一般由两个**或非门**或**与非门**组成。

![image](触发器/image-20240925192438-amfxsr4.png)

![image](assets/image-20240925192455-ed7bas4.png)

其中R表示Reset（复位），S表示Set（复位）。

Q和Q‘称为输出端，并且定义Q\=1、Q’\=0为锁存器的 “ 1 ” 状态;反之为锁存器的 “ 0 ” 状态。

#### D锁存器

前面SR触发器当输入S\=0，R\=0时，输出为不稳定非正常态，为解决这个问题，引入了D型触发器。

D锁存器可以分为前级门电路（2个NAND门和一个非门）和后级SR锁存器（NAND门）组成。通常，使能端E接入时钟信号。

![image](触发器/image-20240925195900-jkgmss1.png)

还可以构建带有 AND 和 NOR 门的 D 锁存器，如下所示。

![image](触发器/image-20240925195909-mw8xrve.png)

因为在 CLK 的有效电平期间输出状态始终跟随输入状态变化，输出与输入的状态保持相同，所以又将这个电路称为 **&quot;透明的 D 型锁存器&quot;（Transparent D-Latch）** 。

锁存器的判断

锁存器很容易在信号上产生毛刺；而且也没有时钟信号，不容易进行静态时序分析。

#### D触发器

D触发器可以由两个D锁存器构成，驱动时钟的相位相反。图中FF1为主锁存器，FF2为从锁存器。​​

![image](触发器/image-20240925194218-iylqig9.png)

- 当CLK=0时：

  CLK1 = 1，主锁存器FF1的电平随输入发生变化

  CLK2 = 0，从锁存器FF2处于锁存状态，输出保持不变

- 当CLK=1时：

  CLK1 = 0，主锁存器FF1处于锁存状态

  CLK2 = 1，从锁存器FF2的电平随输入发生变化

```verilog
//含异步复位和时钟使能的D触发器
module dff(
	input 		clk,
	input		rst_n,
	input		en,
	input 		d,
	output reg 	q
);
	always@(posedge clk or negedge rst_n) begin
		if(!rst_n) begin
			q <= 0;
		end else begin
			if(en) q <= d;
		end
	end
endmodule
```

在实际使用中，D触发器通常由传输门构成。

#### JK触发器

JK触发器由两个输入 **J（置位）** 和 **K（复位）** 、一个时钟输入以及两个 Q 和 Q' 的输出组成。

![image](触发器/image-20240925165636-xdwsqm1.png)

- 当J\=0，K\=0时，触发器的状态维持不变
- 当J\=0，K\=1时，触发器被置成0
- 当J\=1，K\=0时，触发器被置成1
- 当J\=1，K\=1时，触发器翻转

JK触发器是在同步RS触发器的基础上引入两条反馈线构成，从而规避了SR触发器的亚稳态。

JK触发器将输出反馈到输入端，当J和K输入均为1时，输出端驱动输入，导致输出状态翻转，形成一个T（toggle）触发器。

![image](触发器/image-20240925203643-ffs7oho.png)

```verilog
module JK_Trigger (
	input clk,
	input J,
	input K,
	output reg  Q,
	output 		Q1
);
	always@(posedge clk)
	begin
		case({J,K})
			2'b00:Q<=Q;
			2'b01:Q<=2'b0;
			2'b10:Q<=2'b1;
			2'b11:Q<=~Q;
		endcase
	end
	assign Q1=~Q;
endmodule 

```

#### T触发器

T触发器（Toggle Flip-Flop，or Trigger Flip-Flop）只有一个信号输入端T，在时钟有效边沿到来时，T端输入有效信号，则触发器翻转，否则触发器保持不变。

```verilog
module tff(
	input clk,
	input rst_n,
	input T,
	output reg Q
);
	always@(posedge clk or negedge rst_n) begin
		if(!rst) 
			Q<=1'b0;
		else if(T) 
			Q<=~Q;   //当T=1时进行翻转
		else 
			Q<=Q;    //当T=0时保持状态不变
	end
endmodule 

```
