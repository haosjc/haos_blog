我们每天用的手机、电脑，核心都是一颗小小的芯片（Chip）。但它的起点，其实是**沙子**。

## 1. 从沙子到硅

沙子的主要成分是二氧化硅（SiO₂）。经过提纯、还原，可以得到高纯度的**单晶硅**——一种半导体材料。

> 半导体（Semiconductor）的导电能力介于导体与绝缘体之间，这个「居中」的特性，正是它能做成开关的关键。

## 2. 为什么是半导体

导体永远导通、绝缘体永远不通，都没法做「可控开关」。半导体则可以通过**掺杂**与**电压**，精确控制它是通还是断：

| 材料 | 导电能力 | 能否做开关 |
| --- | --- | --- |
| 铜（导体） | 极强 | 否 |
| 硅（半导体） | 可控 | 是 |
| 二氧化硅（绝缘体） | 极弱 | 否 |

## 3. 从晶体管到集成电路

单个**晶体管**（Transistor）就是一个开关。把成千上万个晶体管、电阻、电容刻在同一片硅上，就是**集成电路**（Integrated Circuit，IC）。

```text
晶体管（开关）
   └── 组成逻辑门（与 / 或 / 非）
          └── 组成功能模块（加法器 / 寄存器）
                 └── 组成完整的芯片（CPU / 内存）
```

## 4. 摩尔定律

戈登·摩尔在 1965 年提出：**集成电路上的晶体管数量大约每两年翻一番**。这一定律驱动了半个世纪的性能跃迁，也让芯片制造成为人类最精密的工程之一。

## 小结

理解芯片，记住这条链路即可：**沙 → 硅 → 晶体管 → 集成电路 → 芯片**。下一篇我们聊聊让这一切运转起来的物理基础——PN 结。
